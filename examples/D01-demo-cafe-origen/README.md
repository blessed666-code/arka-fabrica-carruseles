# Ejemplo Demostrativo · D01 (Café de Origen)

Este directorio sirve como modelo de referencia para que veas la estructura exacta que genera la Fábrica de Carruseles de ARKA para cada contenido:

1. **`copy.md`**: El texto redactado para Instagram, TikTok y YouTube Shorts con negritas Unicode nativas (`𝟭.`, `𝟮.`, etc.), espaciado limpio de 2 líneas, sin asteriscos rotos de Markdown y con llamada directa a la acción.
2. **`prompts/`**: La carpeta con los 5 prompts independientes (`01.md` a `05.md`), cada uno con sus candados de fidelidad para el logo y el empaque, la descripción cinematográfica de la escena y las restricciones negativas (`[PROHIBIDO]`).
3. **`01.jpg` a `05.jpg`**: Las 5 imágenes generadas en formato cuadrado 1:1 listas para subir a tus redes.
