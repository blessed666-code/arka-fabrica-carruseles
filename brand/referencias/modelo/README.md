# Carpeta de Fotos de Modelo (Persona Real o Modelo IA)

Esta carpeta es **opcional**. Úsala únicamente si deseas que una persona fija (tú mismo como dueño de negocio, un embajador, un influencer o un modelo generado con IA) protagonice las publicaciones con el mismo rostro y apariencia en todas las fotos.

### 📸 Requisitos de Fotos Multi-Ángulo:
Para que la IA mantenga la consistencia milimétrica de identidad, sube entre 4 y 6 fotos:
1. `rostro-frente.jpg`: Mirando de frente a cámara con iluminación natural clara.
2. `rostro-3cuartos-izq.jpg`: Rostro en ángulo de 3/4 hacia la izquierda.
3. `rostro-3cuartos-der.jpg`: Rostro en ángulo de 3/4 hacia la derecha.
4. `perfil.jpg`: Vista lateral de perfil.
5. `cuerpo-entero.jpg` (opcional): Foto de cuerpo completo de pie si deseas tomas de cuerpo entero.

La IA anclará estas facciones exactas en cada escena de estilo de vida.
