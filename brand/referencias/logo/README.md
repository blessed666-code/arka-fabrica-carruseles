# Carpeta de Logo Oficial

Coloca aquí el archivo de logotipo de tu marca:
- Nombre recomendado: `logo.png`
- Formato: PNG con fondo transparente y buena resolución.
- Es el archivo que la IA pasará como referencia obligatoria en cada slide para garantizar que no se distorsione ni se le añadan ramas, marcos o fondos blancos.
