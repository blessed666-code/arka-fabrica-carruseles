# Carpeta de Fotos de Productos y Empaques

Coloca aquí las fotografías reales de tus productos:
- Toma fotos nítidas con buena luz de frente.
- Asegúrate de que la etiqueta frontal sea 100% legible.
- Muestra el material real del empaque (vidrio, bolsa kraft, cartón, tela, aluminio).
- Nombres recomendados: `producto1.jpg`, `empaque-combo.jpg`, etc.
- La IA utilizará estas fotos como candado de fidelidad para que el producto renderizado sea idéntico al que entregas a tus clientes.
